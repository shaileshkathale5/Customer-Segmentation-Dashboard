# Customer Segmentation Dashboard

## 📌 Project Overview
The Customer Segmentation Dashboard is a Power BI project developed to analyze customer demographics, income, and spending behavior. The dashboard provides meaningful insights through interactive visualizations and helps understand different customer segments for business decision-making.

---

# 🎯 Objectives
- Perform data cleaning using Power Query
- Analyze customer spending patterns
- Segment customers based on age and spending behavior
- Create interactive and professional visualizations
- Build an attractive and user-friendly dashboard

---

# 📂 Dataset Information
Dataset Used: Mall Customers Dataset

### Dataset Columns
- CustomerID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1-100)

---

# 🛠 Tools & Technologies Used
- Power BI
- Power Query
- DAX
- Data Visualization Techniques

---

# 🧹 Data Cleaning Process
The following cleaning steps were performed in Power Query:

- Removed duplicate rows
- Fixed null values
- Changed incorrect data types
- Created Age Group column
- Created Spending Category column
- Trimmed and cleaned text values

---

# 📊 Dashboard Features

## KPI Cards
- Total Customers
- Average Income
- Average Spending Score

## Charts & Visuals
- Gender Distribution Pie Chart
- Age Group Bar Chart
- Spending Category Donut Chart
- Interactive Gender Slicer

---

# 📈 Key Insights
- Adult customers represent the largest customer group
- High spending customers contribute significantly to sales potential
- Gender distribution is almost balanced
- Spending behavior varies across different age groups
